# 抖+ 0.3.3-preview

独立抖音增强模块。实际参考及测试目标是用户提供的 **抖音 40.7.0 / Android 14**。不是 Dyyds 等参考 APK 的完整克隆，不包含它们的 DEX、native、加密载荷或授权材料。

## 当前交付

- 抖+-0.3.3-preview.apk：已签名的适配预览包；已通过 phone MCP 覆盖安装到本轮设备。
- 保持包名 `com.yolo.dyfusion`，同签名可覆盖保留设置；应用名、菜单和入口显示为“抖+”。
- 88 个功能/参数设置项，不等于 88 个独立且全面验证的功能。
- 整个评论增强分组及 Hook 已删除；“隐藏发条评论输入栏”只是界面隐藏项，不恢复评论增强功能。

## 已完成并经用户/真机核对的核心变化

- 顶底标签移除：整标签 GONE，剩余标签补位；商城/朋友例已实际核验。
- 整顶栏、整底栏、收藏容器、音乐转盘、拍同款转盘可独立控制。
- 相关搜索、合集、音乐、拍同款：独立播放/暂停透明度；相关搜索和合集另有整条隐藏开关。
- 详情页“搜你想看的”、底部“发条评论”、听抖音入口、左上“<”：独立隐藏，系统返回方式保留。
- 分享面板好友头像列表及空白区域收起；下方“抖+功能”入口保留。
- 视频按实际 SurfaceView 的显示位置居中，检测宿主重置 translation，避免重复累加偏移。
- 主界面分组移除无实现占位；标签/菜单多选、九宫格双击/长按、单控件扫描和预览。

## 设置位置

- **界面**：标签、整栏、各按钮、相关搜索/合集整条、详情搜索、返回按钮、评论输入条、听抖音。
- **透明度**：播放/暂停分别调顶栏、文案、右侧、底栏、相关搜索、合集、音乐、拍同款。
- **播放**：画面居中/垂直微调、防溢出、默认画质模式、倍速和播放完成行为。
- **菜单**：分享好友列表、分享菜单项、长按菜单项。
- **手势**：九宫格；未设置的区域保留抖音原动作，默认关闭。
- **快捷操作**：悬浮球、音量加后音量减菜单、分享面板抖+入口。

## 当前手机保留的设置

原非评论配置未重置；后来用户明确要求的相关搜索、合集、音乐、分享好友列表、详情搜索、返回箭头、评论输入条、听抖音隐藏已开启。悬浮球保持关闭，九宫格保持关闭，画质恢复“跟随抖音”。测试中临时移除的商城/朋友已恢复原配置。

## 重要边界

- 预览版，不是所有 Android/抖音版本兼容保证。40.7.0 特定 ID 只在此版本使用，未知界面不猜测整页。
- 最高档和最高档直链只使用实际返回的官方 CDN 地址；不保证取得原始上传文件、4K 或独立无水印上传源。没有绕过付费、DRM、登录或验证。
- 分享/长按菜单只对已识别的布局处理；未命中可从音量键菜单打开抖+。
- 控件隐藏只作用于当前作品。极速版的金币/赚钱入口在标准版不存在，本版不冒充完成极速版测试。
- 恢复旧版长按播放控制开关尚未完成，没有放置假开关。
- 发生异常可关闭总开关；无法进入抖音时在 Vekta/LSPosed 关闭本模块并重启抖音。不删除抖音数据。
- 仍有掉帧波动，不能宣称完全解决卡顿；性能记录见测试报告。

## 验证

44 项纯 Java 逻辑断言、44 项 Android 自检；编译成功；Lint 0 错误 0 警告；APK v2 签名验证通过。更多效果与限制见测试报告。

源码包不包含 local.properties、构建缓存、原参考 APK、反编译源码或用户配置备份。debug APK 不是正式发行证书；不同机器重新构建的 debug 签名不同，不能直接覆盖本轮签名包。
